# Dota 2 Mobile — установка с телефона

1. Нажмите **Dota2.apk** ниже → браузер телефона скачает файл → «Установить»
   (разрешите «Установку из неизвестных источников»). APK подписан release-ключом.
2. Откройте приложение: сразу запустится **ДЕМО** — наш собственный рендерер
   с 28 сенсорными кнопками. Это **не Source 2 и не Dota 2**, но позволяет проверить
   экран управления без 30 ГБ файлов. Кнопка «Назад» → меню.
3. В меню «**Скачать рантайм**» → ProgressBar скачает и распакует два ZIP
   (`dota2-runtime-core.zip`, `dota2-goldberg.zip`) в память приложения.
   Это только открытые компоненты Wine/Box64/Turnip/Vortek/Goldberg.
4. «**Загрузить контент**» — вставьте приватную ссылку на ZIP с вашей собственной
   копией папки `dota 2 beta`; распакуется в `/sdcard/Dota2/`.
   Файлы Valve **не** хранятся в репозитории и не публикуются в Releases.

Честно: играбельный матч с ботами требует полного контента, WSI-шима Vulkan,
XServer и оффлайн-GC (M4–M6) и проверки на реальном устройстве.
Подробности: `docs/07-MOBILE-ONLY.md`.
