# Юридические и технические риски (прочитать до загрузки файлов)

Это не «дисклеймер ради дисклеймера»: каждый пункт ниже — конкретное ограничение,
которое сломает пайплайн или репозиторий, если его проигнорировать.

## 1. Бинарники Valve и DMCA

* Файлы из `Steam/steamapps/common/dota 2 beta/` — **проприетарные произведения
  Valve**. Steam Subscriber Agreement не разрешает их публикацию/распространение.
* Публичный коммит `dota2-win64-bins.zip` (186 МиБ в сжатом виде) почти наверняка
  приведёт к **DMCA-takedown репозитория**, а заодно к блокировке аккаунта.
* Технические лимиты GitHub: обычный файл ≤ **100 МБ** (push будет отклонён),
  LFS — около 1 ГБ бесплатного хранилища и трафика, Release asset — до 2 ГБ, но
  публичный.
* Валидатор и `.gitignore` в этом репозитории настроены так, чтобы **ни один
  `.dll`/`.exe`/`.zip` не попал в Git**: `assets/incoming/`, `*.zip`, `*.dll`,
  `*.exe`, `*.vpk`, `*.tzst`, `report/` (отчёты можно коммитить точечно).

**Рекомендация:** на время работ сделать репозиторий приватным, передать ZIP как
**приватный Release asset** или вообще не загружать в GitHub (анализ локально →
в Git только `report/*.md`). См. [04-FILE-MANIFEST, раздел 5](04-FILE-MANIFEST.md).

## 2. Производные работы при статической рекомпиляции (Путь А)

Сгенерированный из PE C/C++ код — производное произведение. Даже pcrecomp
добавил `tools/audit_repo.py` и `docs/PUBLISHING.md` с прямым правилом
«lifted output never goes in git». Поэтому:

* `tools/gen_glue_inventory.py` генерирует **только имена API** и скелет таблицы,
  не тела функций;
* `path-a-probe.yml` публикует каталог функций/логи, но не lifted C;
* любые реальные эксперименты с лифтингом делайте локально и не коммитьте результат.

## 3. Steam ToS, Goldberg и VAC

* Goldberg Emulator заменяет `steam_api64.dll` и **не обходит DRM**
  [2](https://github.com/inflation/goldberg_emulator); его легальное применение —
  LAN/оффлайн запуск уже купленной/бесплатной игры без клиента Steam.
* Dota 2 в SteamDB помечена **VAC (Valve Anti-Cheat)**
  ([appinfo](https://steamdb.info/app/570/depots/)). Оффлайн-матч с ботами античит
  не затрагивает, но **любая попытка выхода в онлайн/matchmaking с эмулятором**
  — нарушение Steam ToS и риск бана аккаунта. Проект ограничивается оффлайном.
* Не используйте реальный аккаунт/пароли/токены в CI. `GH_TOKEN` предоставляется
  Actions автоматически; никаких Steam-креденшелов в репозитории быть не должно.
* DLC «Dota 2 – Vulkan support» (AppID 476580) — бесплатный, но должен быть
  получен через ваш Steam-аккаунт, а не из сторонних архивов.

стороннего бинарника**: `runtime/fetch.py` скачивает их только во время сборки,
и шаг помечен `continue-on-error`.

## 5. Товарные знаки

Иконка и название «Dota 2» в APK сделаны как **нейтральный векторный знак** и
техническая метка для личного использования. `Dota 2`, `Steam`, `Valve`, `Source 2`
— товарные знаки Valve Corporation. Проект не аффилирован с Valve и не должен
выглядеть как официальный продукт; публикация в сторах/распространение под этим
именем потребует отдельного разрешения. `LICENSE` содержит явное уведомление.

## 6. Технические риски устройства

| Риск | Комментарий |
|---|---|
| `targetSdk 28` | Необходим для `execve` распакованных ELF; на Android 14+ система может показывать предупреждение о старом targetSdk, sideload обязателен |
| 25–40 ГБ на `/sdcard/Dota2/` | Плюс ~500 МБ распакованного рантайма; проверьте свободное место |
| 8–12 ГБ ОЗУ | `client.dll` 102 МиБ + `server.dll` 84 МиБ + Wine + JIT-кэши Box64/FEX |
| Turnip только для Adreno | Mali/Xclipse — Vortek/Zink/`bionic-vulkan-wrapper`, возможна несовместимость форматов |
| V8 JIT под эмулятором | Работает, но дорого по CPU; первые минуты возможен сильный stutter |
| Нагрев/троттлинг | Три слоя трансляции: CPU + Win32 + Vulkan [1](https://tech-insider.org/winlator-vs-box64-vs-wine-2026/) |
| VAC / онлайн | Не запускайте онлайн-режим с эмулятором Steam |
| Обновления игры | Депо 373303 обновился **03.11.2026**; после каждого патча размеры и импорты меняются — перезапускайте `pe-analysis` |

## 7. Про «я обещаю рабочий APK»

В репозитории намеренно **нет** утверждения «Dota 2 запускается». Есть:

* рабочий анализатор (проверен selftest'ом);
* собираемый APK-каркас;
* пинованные апстрим-компоненты;
* документированные гейты M0–M6 с критериями проверки.

Подтверждённых открытых профилей совместимости Dota 2 под Winlator/GameNative с
логами я не нашёл; ролик [«DOTA 2 on ANDROID is REAL»](https://www.youtube.com/watch?v=_0dOtZSxu-M)
(декабрь 2025) — непроверенное свидетельство. Любой «успех» без `WINEDEBUG=+loaddll`
логов и `vkCreateAndroidSurfaceKHR` в трейсе считать доказанным нельзя.
